สูตรคำนวณปริมาณซื้อขาย 30 วันตามที่หน้าเว็บระบุไว้:

> ปริมาณรวม 30 วัน = ปริมาณสปอต (รวม Convert) + ปริมาณหุ้น + ปริมาณฟิวเจอร์ส × 40% + ปริมาณฟิวเจอร์ส USD1 × 20% + ปริมาณออปชัน × 20% + ปริมาณ CFD × 10%

## ขั้นตอนที่ 1: สมัครบัญชีและยืนยันตัวตน

### เปิดบัญชี

สมัครด้วยอีเมลหรือเบอร์โทรศัพท์ ตั้งรหัสผ่านที่ผสมตัวพิมพ์ใหญ่ ตัวเลข และสัญลักษณ์ แล้วยืนยันผ่านรหัสที่ส่งไปทางอีเมลหรือ SMS

ตรงนี้ยังไม่ต้องรีบร้อน แต่มีจุดที่ควรรู้: **ยังไม่ทำ KYC ก็สมัครได้** และยังเข้าไปดูข้อมูลตลาดได้ แต่จะเติมเงิน ถอนเงิน เทรดจริง ใช้บริการเงินตรา หรือขอ การ์ด ไม่ได้ ฉะนั้นถ้าเป้าหมายคือเทรดจริง ข้ามขั้นนี้ไปก็เสียเวลาเปล่า

### KYC ทำตรงไหน

บนเว็บ: กดรูปโปรไฟล์ → ตัวตน → ยืนยันทันที

บนแอป: โปรไฟล์ → KYC → ยืนยันทันที

เอกสารที่ใช้ได้คือหนังสือเดินทาง บัตรประชาชน หรือใบขับขี่ที่ออกโดยหน่วยงานรัฐ พร้อมถ่ายภาพใบหน้าเพื่อยืนยันตัวตน ระยะเวลาอนุมัติไม่ตายตัว บางบัญชีผ่านเร็ว บางบัญชีมีคำขอเอกสารเพิ่มก็ยืดออกไป อย่าไปเชื่อตัวเลข "ไม่กี่นาที" แบบตายตัว

ถ้าต้องการเพดานการเติม–ถอนที่สูงขึ้น มีขั้น **Verified Plus** ที่ต้องยื่นหลักฐานที่อยู่เพิ่ม เช่น ใบแจ้งค่าสาธารณูปโภค

### เรื่องภูมิภาคที่คนไทยมักไม่เช็ค

Gate มีสถานะการกำกับดูแลในหลายเขตอำนาจ อาทิ ใบอนุญาตเต็มรูปแบบจาก VARA ในดูไบ (2025) และใบอนุญาต MiCA จาก MFSA มอลตา (ตุลาคม 2025) และจดทะเบียนในออสเตรเลียผ่าน AUSTRAC ถ้าคุณไปอยู่หรือย้ายถิ่นในเขตที่ถูกจำกัด สินค้าบางตัวจะไม่โชว์ขึ้นมาให้ใช้ — ซึ่งไม่ใช่บั๊ก แต่เป็นข้อกำหนดด้านกฎระเบียบ

## ขั้นตอนที่ 3: เติมเงินเข้า Gate มี 3 ทางหลัก

หน้าเติมเงินสำหรับผู้ใช้ใหม่ตอนนี้ให้ทางเลือกหลักสามแบบ: **C2C**, **เติมเงินบนเชน** และ **ซื้อ–ขายด้วยบัตรเดบิต/เครดิต** ทางไหนใช้ได้จริงขึ้นอยู่กับบัญชีและภูมิภาคของคุณ

### C2C

ซื้อขายกับผู้ใช้รายอื่นโดยตรง เหมาะกับคนที่ยังไม่มีคริปโตเลยและอยากได้ USDT เป็นทุนตั้งต้น

### เติมเงินบนเชน

ไปที่ เติมเงิน → เติมเงินบนเชน → เลือกเหรียญ → เลือกเครือข่าย ระบบจะสร้างที่อยู่กับ QR Code ให้

จุดที่พลาดกันบ่อยที่สุดและเจ็บที่สุด: **เครือข่ายต้องตรงกันทั้งสองฝั่ง** ถ้าคุณเติม USDT ผ่านเครือข่าย Tron ฝั่งที่ส่งมาก็ต้องเลือกเครือข่ายที่รองรับ Tron เหมือนกัน อย่าดูแค่ชื่อเหรียญแล้วส่งข้ามเชน เพราะเงินที่ส่งผิดเครือข่ายกู้คืนยากมากและบางกรณีคือกู้ไม่ได้เลย

อีกอย่างที่ควรอ่านก่อนกดส่ง: ใต้ชื่อเหรียญและเครือข่ายจะมี **ยอดขั้นต่ำ** กำกับอยู่ ยอดที่ต่ำกว่านั้นอาจไม่เข้าบัญชี

ข่าวดีคือ **การเติมเงินบน Gate ไม่มีค่าธรรมเนียม** ส่วนค่าธรรมเนียมจะไปเกิดตอนถอน ซึ่งคิดตามสถานะความแออัดของเครือข่ายแบบเรียลไทม์

## ขั้นตอนที่ 4: ซื้อขายสปอตครั้งแรก

เส้นทางบนเว็บตอนนี้คือ **เข้าสู่ระบบ → ซื้อขาย → สปอต** แล้วใช้แถบตลาดด้านซ้ายในการค้นหาคู่เงิน Gate ระบุว่ารองรับสินทรัพย์ดิจิทัลสำหรับสปอตเทรดมากกว่า 4,800 รายการ

หน้าเทรดจะประกอบด้วยข้อมูลคู่เงิน, แท่งเทียน (K-line), แผงสั่งซื้อขาย, แท็บประเภทคำสั่ง, สมุดคำสั่ง (Order Book), รายการตลาด, คำสั่งค้าง–ประวัติการซื้อขาย และยอดสินทรัพย์

บนมือถือ แตะเมนู **ซื้อขาย** ที่แถบล่าง แล้วเลือกคู่เงิน กรอกพารามิเตอร์ ดูสมุดคำสั่ง เปิดกราฟได้ในหน้าเดียว

### Market กับ Limit ต่างกันตรงไหน

คู่ **BTC/USDT** เป็นตัวอย่างที่เห็นภาพง่ายที่สุด: BTC คือสินทรัพย์ฐาน USDT คือสินทรัพย์ที่ใช้จ่าย ถ้า BTC ขึ้นป้าย 80,000 USDT แปลว่าในสมุดคำสั่งนั้น 1 BTC ถูกประเมินไว้ประมาณ 80,000 USDT

- **Market** เน้นความเร็วในการจับคู่ทันที แลกมาด้วยราคาที่ไม่แน่นอน ถ้าคำสั่งใหญ่ในตลาดที่สภาพคล่องตื้น มันจะไล่กินหลายระดับราคาแล้วได้ราคาเฉลี่ยแย่ลง — นี่คือสลิปเพจ Gate มีกลไกป้องกันสลิปเพจเฉพาะคู่เงิน ถ้าเกินกรอบที่กำหนด ส่วนที่เกินอาจถูกยกเลิก

- **Limit** คุณกำหนดราคาเองได้ เช่นอยากซื้อที่ 78,000 USDT ขณะตลาดอยู่ 80,000 ก็ตั้งรอได้ แต่คำสั่งอาจไม่ถูกจับคู่เลยจนกว่าจะยกเลิก หรือกว่านั้นคือทุกอย่างยังค้างอยู่ในรายการ "คำสั่งปัจจุบัน"

### ก่อนกดยืนยัน ให้เช็ค 6 อย่างนี้

คู่เงินถูกไหม, ทิศทาง buy/sell, ประเภทคำสั่ง, ราคา, จำนวน และยอดรวม

เรื่องนี้ไม่ใช่การพูดเล่น หน้าเทรดของทุกแพลตฟอร์มมีคนกรอกผิดคู่เงินทุกวัน และการคลิกยืนยันคือจุดที่ย้อนกลับไม่ได้

### ค่าธรรมเนียมคิดจากยอดที่ "จับคู่ได้" เท่านั้น

If คำสั่งถูกจับคู่บางส่วน ค่าธรรมเนียมคิดเฉพาะส่วนนั้น ส่วนที่ยังไม่จับคู่ไม่มีค่าใช้จ่าย ถ้ายกเลิกก่อนมีการจับคู่ ก็ไม่เสียค่าธรรมเนียม

### ประเภทคำสั่งที่เกินกว่ามือใหม่จะได้ใช้

นอกจาก Market และ Limit แล้ว Gate ยังมี Stop-limit, TP/SL, Iceberg (แสดงคำสั่งใหญ่แค่บางส่วน), TWAP (ซอยเวลายิงคำสั่ง), คำสั่งแบบวนซ้ำ และ Trailing order เครื่องมือเหล่านี้แก้ปัญหาการExecute คนละแบบ ไม่ได้ดีกว่าคำสั่งพื้นฐานโดยอัตโนมัติ เช่น Stop-limit ควบคุมราคาได้ดีกว่าตอนที่ถูกกระตุ้น แต่ถ้าตลาดวิ่งผ่านราคาเร็ว ๆ คำสั่งก็ไม่ถูกจับคู่ได้เหมือนกัน
